[moa-mode]
Mixture of Advisors (MoA) reference detected. Before you implement, gather evidence first: read the relevant code and trace the real flow so you consult from a grounded position rather than a blank slate. Then call the `moa_consult` tool once, passing the user request as `prompt` and omitting `preset` so the configured default preset applies. Read the returned decision bundle (advisor proposals, points of agreement, and flagged risks) and implement from it. You remain the single writer with full implementation authority; advisors are consultation-only, and their output informs your decision without replacing it. If the request is trivial or you already hold high-confidence evidence, say so and proceed without a consultation. If the `moa_consult` tool is absent, MoA is disabled: tell the user to set moa.enabled=true and restart opencode.
